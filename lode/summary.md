# CloudOStat Project Summary

CloudOStat is a cross-platform temperature monitoring and control system for outdoor smokers/grills. A Meadow F7 Feather microcontroller reads three thermocouples (air + two meat probes), controls a heater relay, displays status on a local LCD, and reports telemetry to **Azure IoT Hub** via MQTT. The app layer — .NET MAUI (desktop/mobile) and Blazor Web (server + WebAssembly) — reads device twin reported properties and writes desired properties through the IoT Hub REST API, authenticated with SAS tokens from a shared access policy key. An .NET Aspire AppHost orchestrates the web server during development. Built on .NET 10 with MudBlazor, centralized package management, and a shared component library for cross-platform UI consistency.
